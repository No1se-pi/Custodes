custodes

Локальный security pipeline для Git-коммитов. Ищет секреты и высокоэнтропийные токены, а затем запускает SonarQube Quality Gate — ещё до попадания кода в историю.

Минимальный сторож перед каждым коммитом

Custodes соединяет быстрый локальный secret scan и полноценный статический анализ. Каждый этап прозрачен, настраивается отдельно и может остановить commit с понятной причиной.

01

Проверяет staged diff

Команда custodes check смотрит только файлы, добавленные через git add, и ищет совпадения в новых строках.

02

Блокирует commit

При найденном секрете CLI завершает проверку с ошибкой, а pre-commit hook не дает коммиту пройти дальше.

03

Настраивается через .env

Можно задать banwords, включить ASCII-логотип и выбрать язык сообщений для локальной команды.

04

Находит токены по энтропии

Эвристика Shannon entropy замечает случайные ключи и токены, даже если их название ещё не добавлено в правила.

05

Проверяет Quality Gate

После чистого secret scan Custodes запускает локальный SonarQube и ждёт итог Quality Gate.

06

Работает на Windows

PowerShell installer, Git Bash launcher и Docker Desktop поддерживаются, включая пути профиля с кириллицей.

Рабочий процесс без лишней магии

Утилита держится рядом с Git и остается понятной: установил hook, добавил правила, проверил индекс.

Install

installer.sh готовит рабочую директорию и команду custodes в локальном окружении.

Init

custodes init добавляет pre-commit hook в текущий Git-репозиторий.

Scan

custodes check проверяет banwords и entropy, не показывая возможный секрет в терминале.

Quality Gate

Если секретов нет, опциональный SonarQube анализирует проект. Commit проходит только после зелёного gate.
